# Universum — десктопный генератор учебных PDF

Десктопное приложение для преподавателей и репетиторов: введите тему (или загрузите файл/расшифровку) → выберите тип, стиль и объём → получите готовый **PDF** с учебным материалом, оформленным в LaTeX.

**$0. Без API-ключей, без оплаты, без авторизации, без истории.** Один документ за раз. На выходе — только PDF.

---

## Быстрый старт

### 1. Требования

- **Python 3.11+** (https://python.org) — с Tkinter (на Windows/macOS Tkinter входит в установщик; на Linux: `sudo apt install python3-tk`) и пакетом `customtkinter` (ставится из `requirements.txt`).
- **Интернет** — для бесплатной нейросети и (опционально) веб-поиска. При первом запуске LaTeX-движок Tectonic скачается автоматически (~30 МБ, один раз).
- **LaTeX-движок** (один из вариантов, по приоритету):
  - **Tectonic** — скачивается автоматически с GitHub, ничего устанавливать не нужно; или
  - **TeX Live** / **MiKTeX** / **MacTeX** — если уже установлены, будут найдены автоматически (`tectonic` → `xelatex` → `pdflatex` → `lualatex`).
- **Tesseract** (только для OCR изображений/сканов): https://github.com/tesseract-ocr/tesseract — без него текстовые файлы работают как обычно.

### 2. Установка

```bash
git clone https://github.com/isakahram/universum.git
cd universum
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

> Обязателен только `customtkinter` — он рисует интерфейс. Ядро (генерация, компиляция, поиск) работает на стандартной библиотеке Python, а пакеты для парсинга PDF/DOCX/PPTX и OCR опциональны: без них приложение запустится, но эти форматы будут недоступны (появится понятное сообщение).

### 3. Запуск

```bash
python main.py
# или
python -m universum.main
# или (после pip install -e .):
universum
```

### 4. Сценарий использования

1. Введите **запрос**: тему, аспекты, пожелания к содержанию и стилю. Язык документа определится автоматически (русский/английский).
2. **Необязательно:** загрузите файл (PDF, DOCX, DOC, TXT, PPTX, изображение/скан). Если есть и файл, и запрос — файл основа содержания, запрос — инструкция («упростить язык», «добавить примеры», «сохранить авторские формулировки»). Расшифровка Zoom (TXT) — тоже сюда.
3. **Необязательно:** введите желаемую **структуру** (разделы по порядку). Если пусто — будет стандартная для типа.
4. В панели под полем выберите **тип** (Лекция / Конспект / Домашнее задание / Тест), **стиль** (Строгий / Красочный / Без стиля) и **объём** слайдером: страницы — для лекции/конспекта/ДЗ, вопросы + варианты — для теста.
5. **Необязательно:** разверните «Дополнительно ▾» и включите «Искать свежие данные в интернете» — в PDF появится раздел «Источники» с реальными ссылками и датой.
6. Нажмите **«Сгенерировать PDF»** (или `Ctrl+Enter`) → дождитесь прогресса → **«Сохранить PDF»**.

При ошибке компиляции LaTeX приложение **само чинит код нейросетью (до 3 попыток)**. Если не получилось — покажет окно с логом компилятора.

## Как это устроено (архитектура)

```
Запрос/файл ──► file_parser ──► текст
                    │
(опц.) веб-поиск ──► web_search (DuckDuckGo) ──► источники
                    │
                    ▼
              prompts (тип × стиль) ──► llm_client ──► LaTeX-код
                    │                        (Pollinations, без ключа)
                    ▼
              latex_compiler ──► PDF ──► GUI (скачивание)
              (Tectonic/TeX Live + авто-ремонт до 3 попыток)
```

### Обоснование стека

| Компонент | Выбор | Почему |
|---|---|---|
| Язык | **Python 3.11+** | Кроссплатформенность, стандартная библиотека покрывает HTTP/JSON/архивы |
| GUI | **customtkinter** (поверх Tkinter) | Современные скруглённые виджеты, тёмная/светлая тема автоматически (Windows/macOS/Linux), $0, без сборки |
| Нейросеть | **Pollinations.ai** (`https://gen.pollinations.ai/v1/chat/completions`, модель `openai`, OpenAI-совместимый) | Бесплатный ключ Pollinations (или анонимно с меньшими лимитами). | Логи | `logs/universum.log` | Без персональных данных (текст пользователя только обрезанным превью) |

### Типы документов

- **Лекция:** титульный лист, оглавление, введение (актуальность, цели), 3–5 разделов, примеры/кейсы, выводы, литература.
- **Конспект:** тезисы, определения, формулы, итоговая шпаргалка — сжато, без воды.
- **Домашнее задание:** задания по уровням сложности (базовый/стандартный/повышенный), критерии оценивания, **без решений**.
- **Тест:** вопросы (один ответ / множественный выбор / открытые), в конце — ключ ответов с эталонами.

### Стили

- **Строгий:** академическая вёрстка, serif, чёрно-белая гамма, строгая нумерация, титульный лист + оглавление.
- **Красочный:** цветные блоки `tcolorbox`, акценты `maincolor/accentcolor`, креативные заголовки.
- **Без стиля:** минимум оформления, стандартный LaTeX, без цветов.

### Качество LaTeX

### Шаблон оформления (фиксированная преамбула)

Начиная с этого шаблона **преамбула задаётся кодом**, а не нейросетью:

1. Модель возвращает **только тело** документа (`prompts.SYSTEM_PROMPT`).
2. `prompts.build_preamble(style, language)` собирает преамбулу стиля: пакеты, цвета, шрифты, окружения-блоки, титульный лист.
3. `prompts.wrap_document(body, style, language)` склеивает готовый документ:
   `% !TEX program = pdflatex` → преамбула → `\begin{document}` → тело → `\end{document}`.

Что это даёт: сломать пакеты/кодировку модель не может; смена стиля меняет только преамбулу (текст не перегенерируется); кириллица настраивается один раз и одинаково для всех документов.

**Доступные модели команды** (одинаковы во всех стилях):

| Конструкция | Назначение |
|---|---|
| `\makelecturetitle{Курс}{Семестр}{Лекция}{Тема}` | титульный лист (обязательная первая строка тела) |
| `\begin{definition}` | определения, термины (бирюзовая плашка / строгая рамка / абзац) |
| `\begin{theorem}` | теоремы, законы, правила |
| `\begin{example}` | примеры, разборы задач |
| `\begin{important}` | предупреждения, типичные ошибки |
| `\begin{keyidea}` | ключевая мысль раздела/лекции |
| `\term{...}`, `\hl{...}` | термин, маркерное выделение |

**Стили** (различаются только преамбулой):
- `Красочный/креативный` — полный шаблон: цветные блоки tcolorbox, иконки fontawesome5, титульный лист с плашкой (tikz), цветные заголовки.
- `Строгий` — те же блоки и структура, но монохром: чёрные рамки, без иконок, строгий титул с линейкой.
- `Без стиля` — минимум: блоки как простые абзацы, без tcolorbox, иконок и цветов.

**Кириллица.** В преамбуле `iftex`: под `pdflatex` — `T2A` + `inputenc` + `lmodern`, под `xelatex`/`lualatex` (в т.ч. Tectonic) — `fontspec`. Основной язык babel ставится последним (`english,russian`) под язык документа.

**Про шрифты (важно).** Ни `helvet`, ни Latin Modern, ни TeX Gyre Heros кириллицу в нужном начертании не дают (а `fontconfig` в Tectonic может быть недоступен — `Cannot load default config file`, поэтому шрифт по имени семейства там не находится). Решение — только `fontspec` + DejaVu, заданный **по имени файла** (поиск через `kpse`, без fontconfig):

| Движок | Шрифты |
|---|---|
| xelatex / lualatex / Tectonic | `fontspec`: `\setmainfont{DejaVuSerif.ttf}` (DejaVu Serif), `\setsansfont{DejaVuSans.ttf}` (заголовки, титул), `\setmonofont{DejaVuSansMono.ttf}` (листинги); запасной вариант — Liberation Serif/Sans |
| pdflatex | `T2A` + `inputenc` + `lmodern` (кириллица в `T2A`, шрифт менять не нужно) |

Основной шрифт документа — **DejaVu Serif** (`\familydefault` больше не переключается на sans). Если DejaVu нет, берётся Liberation Serif, иначе в лог пишется предупреждение. Массовая потеря кириллицы (`Missing character … U+04xx`) распознаётся (`latex_compiler.has_missing_cyrillic`) и превращается в понятную ошибку вместо PDF с «дырами».

**Математика и доказательства.** Подключены `amsmath`, `amssymb`, `amsthm` — работают окружение `proof` и символ `\qed` (раньше `\qed` давал `Undefined control sequence`).

**Иконки.** Каждая иконка вызывается через `\ifcsname`: в разных версиях `fontawesome5` часть глифов отсутствует (например `\faCalendarAlt`), и без проверки это давало `Undefined control sequence`. Теперь отсутствующая иконка просто не печатается.

**Магическая строка и движок.** Первая строка документа — `% !TEX program = pdflatex`: её понимают TeXstudio/TeXShop (открывают файл с нужным движком). `latex_compiler.engine_from_magic()` читает её и **ставит pdflatex первым**, если он установлен. Tectonic магические строки не читает (он XeTeX-движок) — документ всё равно собирается благодаря `iftex`-ветке, это пишется в лог.

**Запасные варианты.** `tcolorbox`, `fontawesome5`, `tikz` подключаются через `\IfFileExists`: если пакета нет, блоки становятся простыми абзацами, иконки исчезают, титул рисуется линейками — PDF собирается. Ошибка «File `...sty' not found» распознаётся (`latex_compiler.is_preamble_error`): авто-ремонт через LLM не запускается (он тут бессилен), пользователь получает понятное сообщение с просьбой доустановить пакеты.

Ответ модели очищается от markdown-обёрток, из него извлекается тело (`utils.extract_document_body`), документ собирается, проверяется (`validate_latex`), компилируется; при ошибке в теле — до 3 авто-исправлений через LLM, после каждого документ пересобирается заново с исходной преамбулой.

## Интерфейс

Окно собрано на `customtkinter` и выглядит одинаково аккуратно на Windows, macOS и Linux (тема следует системной).

```
        Universum                                  ⚙
        Учебные материалы в PDF за пару минут

  ┌──────────────────────────────────────────────────┐
  │ Опишите, что вы хотите сгенерировать…            │
  │                                                  │
  └──────────────────────────────────────────────────┘
   Лекция ▾        Академический ▾        Объём ──●── 12 страниц

            ┌────────────────────────────────┐
            │      Сгенерировать PDF         │
            └────────────────────────────────┘
            ▓▓▓▓▓▓▓▓▓░░░░░░░  Готовлю документ…
            [Отмена]                       [Сохранить PDF]

  Дополнительно ▾  (файл-источник, структура, веб-поиск)
```

- Технические детали (преамбула LaTeX, компилятор, внутренние пути) в главном окне не показываются — они уходят в лог `logs/universum.log`; лог LaTeX при ошибке открывается в отдельном окне с кнопкой «Копировать».
- Вместо `messagebox` — тосты в правом нижнем углу и аккуратные модальные окна.
- Для теста объём переключается на «вопросы» (5–50) и «варианты» (2–6), для остальных типов — страницы (1–30).

## Конфигурация нейросети (опционально)

Ключ нужен для `gen.pollinations.ai` (бесплатный ключ с https://enter.pollinations.ai) или для своего провайдера. Укажите его в GUI: кнопка **«⚙»** в правом верхнем углу → провайдер → URL, модель, ключ → «Проверить соединение» → «Сохранить».

Вставляйте ключ **как есть**: без слова `Bearer`, без кавычек и без переносов строк — приложение дополнительно очищает ключ от этих артефактов, но лучше копировать чисто.

- Ключ хранится в **OS keyring** (Windows Credential Manager / macOS Keychain) или в `~/.universum/settings.json` с правами `0600`. Он **никогда** не попадает в репозиторий, логи и отчёты (в логах только маскированный вид `sk-...abcd`).
- Ключ отправляется **только** на выбранный удалённый эндпоинт, не на `localhost` (Ollama).
- **Никогда не присылайте ключ в чат, GitHub issues и скриншоты.** Если ключ попал в чат — отзовите его и выпустите новый.

Переменные окружения (имеют приоритет над GUI):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `UNIVERSUM_LLM_URL` | Pollinations | Свой OpenAI-совместимый эндпоинт |
| `UNIVERSUM_LLM_MODEL` | `openai` | Модель на Pollinations |
| `UNIVERSUM_LLM_KEY` | *(пусто)* | Ключ только если ваш эндпоинт его требует |

Локальный Ollama подхватывается автоматически, если запущен (`ollama serve` + `ollama pull llama3.1:8b`).

### Ошибка `401 Unauthorized` (ключ проверен вручную через `curl` и работает)

У `gen.pollinations.ai` ключ **обязателен**, и приложение отправляет его в заголовке `Authorization: Bearer <ключ>`. Если 401 приходит, хотя `curl` с этим же ключом отвечает `pong`:

1. Запустите диагностику **тем же кодом и теми же настройками, что у приложения**:

   ```bash
   python -m universum.diagnose
   ```

   Она покажет провайдера, URL, модель, маску ключа и то, **уйдёт ли** заголовок `Authorization`, а затем сделает пробный запрос.
2. Проверьте, что ключ создан на https://enter.pollinations.ai (`sk_…` / `pk_…`), а не у другого провайдера.
3. Для Pollinations URL должен быть ровно `https://gen.pollinations.ai/v1/chat/completions` (старый `text.pollinations.ai` не поддерживается).
4. Если ключ сохранялся в OS keyring, а система его не отдаёт (Linux без backend-а), приложение сохранит его в `~/.universum/settings.json` (`0600`); диагностика покажет пустой ключ — вставьте его заново.

Сообщение об ошибке в приложении теперь явно говорит, был ли ключ отправлен: «Провайдер требует ключ, но приложение его не отправило» или «Ключ был отправлен».

### Ошибка `can only concatenate str (not "NoneType") to str` при компиляции

Это была ошибка компилятора LaTeX: `latex_compiler.py` склеивал вывод процесса (`proc.stdout`/`proc.stderr`) напрямую, а в GUI-сборке без консоли (или при перенаправленных потоках) они могут приходить как `None` — падал `TypeError`, который маскировался под «Ошибка запуска». Исправлено:

- весь внешний вывод проходит через `_text()` (`None` → `""`, байты → UTF-8), конкатенация строк больше не падает;
- `CompileResult.log` всегда строка, `LatexCompileError.log` тоже;
- `subprocess` запускается с `stdin=DEVNULL` и `encoding="utf-8", errors="replace"` (не падает на cp1251-логах Windows);
- любое непредвиденное исключение превращается в `CompileResult(success=False, log=…)` — GUI показывает лог, а не «вылетает»;
- в логе теперь видно код возврата движка, таймаут и причину отсутствия PDF.

Если после обновления компиляция всё равно не проходит — пришлите текст из лога компилятора (окно «Лог»): там теперь реальная причина (нет движка, нет интернета для Tectonic, ошибка в LaTeX-коде).

### Ошибка `You can't use \spacefactor in internal vertical mode`

Модель использовала внутренние макросы LaTeX (`\@`, `\@title`, `\makeatletter`), что ядро LaTeX запрещает вне `\makeatletter`. Исправлено на двух уровнях:

1. **Промты** (`prompts.py`): в системном промте и в каждом блоке стиля теперь жёсткое правило — символ `@` в командах запрещён, титульный лист собирается **только** через `\title{}`, `\author{}`, `\date{}` и `\maketitle`. Промт авто-ремонта знает эту ошибку и знает, как её править.
2. **Страховка в коде** (`utils.sanitize_latex`): даже если модель проигнорирует правило, перед компиляцией из кода вырезаются `\@`/`\@@`, блоки `\makeatletter…\makeatother` и `\spacefactor`; `\@title`/`\@author`/`\@date` заменяются значениями из преамбулы. Обычный `@` в тексте (e-mail, `5@6`) не трогается.

### Ошибка `[WinError 10061]`

Это «подключение отклонено». Чаще всего — незапущенный Ollama (`localhost:11434`) при недоступном основном сервисе. Приложение теперь показывает ошибки **всех** эндпоинтов. Что проверить: интернет, URL/модель/ключ в настройках, запущен ли Ollama (если выбран локальный провайдер).

## Допущения (приняты по умолчанию)

1. **Язык документа** определяется по языку запроса (кириллица → русский, иначе английский).
2. **Объём** — ориентир: ~500 слов на страницу LaTeX 11pt; модель старается попасть в ±20%.
3. **Источники** при веб-поиске — только реальные URL из результатов DuckDuckGo; выдумывать ссылки запрещено промтом.
4. **Один документ за раз**, история и файлы после закрытия не сохраняются (кроме логов без PII).
5. **Лимиты:** файл ≤ 20 МБ, извлечённый текст ≤ 60 000 символов, запрос ≤ 20 000 символов.
6. **Скачивание .tex не требуется** — только PDF (LaTeX-код остаётся во временной папке на время компиляции).

## Известные ограничения

- **Бесплатная нейросеть** (Pollinations) может быть медленной или временно перегружена — клиент делает retry (3 попытки × цепочка эндпоинтов) и показывает понятное сообщение. Для скорости можно запустить локальный Ollama.
- **Tectonic** при первом запуске скачивает пакеты LaTeX из интернета (нужен интернет один раз); без интернета нужен установленный TeX Live/MiKTeX.
- **OCR** требует системный Tesseract; без него изображения не распознаются (текстовые файлы работают).
- **Старый .doc** читается эвристически (olefile); для надёжности сохраняйте как .docx/.txt.
- **Объём PDF** — приблизительный (зависит от модели и темы); точное число страниц LaTeX не гарантирует.
- **GUI** — customtkinter: современная минималистичная тёмная/светлая тема, крупное поле запроса, слайдеры объёма, тосты вместо модальных ошибок. Сборка в .exe/.app — через PyInstaller (см. `requirements.txt`, закомментирован).

## Тесты

```bash
pip install pytest
pytest -q
```

Тесты не требуют сети, дисплея и LaTeX: LLM/компилятор замоканы, а `tests/test_gui_smoke.py` поднимает окно на заглушках `customtkinter`/`tkinter` и проверяет сборку запроса, обмен сообщениями с оркестратором и диалоги ошибок.
