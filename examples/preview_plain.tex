\section{Основные определения}

\begin{definition}
\term{Определение.} Пусть $X$ — множество. Тогда \emph{мощностью}
множества $|X|$ называется количество его элементов.
\end{definition}

\begin{theorem}
Для любых множеств $A$ и $B$ выполняется:
\[
  |A \cup B| = |A| + |B| - |A \cap B|.
\]
\end{theorem}

\begin{example}
Пусть $A = \{1,2,3\}$ и $B = \{3,4\}$. Тогда:
\[
  |A \cup B| = 4 = 3 + 2 - 1.
\]
\end{example}

\begin{important}
Не путайте \hl{мощность} с количеством \emph{подмножеств} — это разные
характеристики множества!
\end{important}

\section{Примеры и задачи}

\begin{enumerate}
  \item Найдите мощность множества $\{x \in \mathbb{N} \mid x < 10\}$.
  \item Докажите формулу включений-исключений для трёх множеств.
  \item Приведите практический пример из вашей предметной области.
\end{enumerate}
